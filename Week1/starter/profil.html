Cara Mengakses File PHP via XAMPP

  1. Buka XAMPP Control Panel
  2. Klik Start di sebelah Apache
  3. Taruh file PHP di folder C:\xampp\htdocs\
  4. Buka browser dan ketik http://localhost/namafile.php
